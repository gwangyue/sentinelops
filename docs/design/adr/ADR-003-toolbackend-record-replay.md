# ADR-003 工具后端支持录制和回放

- 状态：已接受（2026-11-09）
- 相关：01 篇 §3.1、06 篇

## 背景

每次评测都真实注入故障，一轮评测要花几个小时，而且故障的表现每次不完全一样，导致评测结果无法复现。

## 决策

所有只读工具都通过 `ToolBackend` 接口调用，后端有三种实现：Live、Record、Replay。

- 回放时，用（工具名, 规范化之后的参数）作为键，查找录制下来的输出。
- 找不到就记为 `replay_miss`，不访问集群，也不做模糊匹配。
- 录制时，同时保存"执行动作之后"的观测结果，供回放模式下的验证步骤使用。

## 放弃的方案

| 方案 | 放弃原因 |
|---|---|
| 每次评测都真实注入故障 | 慢；结果无法复现 |
| 用 mock 函数模拟工具输出 | 输出是人写出来的，不真实，评测结果会偏乐观 |
| 回放找不到时按相近的参数模糊匹配 | 会让分数虚高 |

## 后果

- 好处：评测可以复现，迭代速度达到分钟级；改动提示词时不需要启动集群。
- 代价：新版本 Agent 调用了录制时没调用过的工具或参数时，回放会找不到对应输出（`replay_miss`）。需要监控覆盖率，覆盖率低时重新录制。
