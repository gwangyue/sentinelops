# ADR-010 03 篇 pack.yaml 示例补上 es.hot_threads 的输出预算

- 状态：已接受（2026-11-10）
- 相关：03 篇 §3.1；ADR-009

## 背景

03 §3.1 规定：没有声明 `output_budget_tokens` 的工具不允许注册。但同一节的 `pack.yaml` 示例里，`es.hot_threads` 没有写这个字段，示例违反了它自己的约束。M1 D1 的契约测试直接从文档解析示例，因此发现了这个问题。

## 决策

给示例里的 `es.hot_threads` 补上 `output_budget_tokens: 600`。只改示例，契约结构和约束都不变。

## 后果

契约测试改为原样解析示例；另外用一条单独的测试确认“缺少输出预算的工具会被拒绝”。
