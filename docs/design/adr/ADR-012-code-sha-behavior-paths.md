# ADR-012 code_sha 只对影响行为的内容计算哈希

- 状态：已接受（2026-11-10）
- 相关：03 篇 §5.2；ADR-008

## 背景

`VersionComponents.code_sha` 原来取的是 git HEAD。D3 发现，只改文档的提交也会让当前版本失效：巡检被拒绝，必须重新冻结一个行为完全相同的版本，收敛曲线上会多出没有意义的点。

## 决策

- `code_sha` = HEAD 中 `src/`、`config/`、`uv.lock`、`pyproject.toml` 这几个路径的 git 对象哈希，合起来再算 sha256。依赖版本也会改变行为，所以锁文件和 pyproject 也算在内。
- 这些路径里有未提交的改动（包括未跟踪的新文件）时，`sentinel version freeze` 和开始调查都拒绝，并提示先提交。
- 03 §5.2 的注释同步修改。字段名和类型不变。

## 后果

- 改文档、测试、部署脚本不再需要重新冻结。
- 代价：`tests/` 里的假模型剧本等内容不在哈希范围内。它们只影响测试，不影响真实运行的 Agent，所以不纳入。
